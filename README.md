## 錦江町森林管理システム（app フォルダ）

スマホのブラウザで使える、地番と境界線の地図アプリの試作品です。

- 背景地図：国土地理院 地理院タイル（標準地図・写真）
- 地番データ：法務省 登記所備付地図データ（G空間情報センター／AIGID が GeoJSON に変換したもの、CC BY）
- 森林簿：鹿児島県 森林簿オープンデータ（地番で照合し、林小班・樹種・林齢・蓄積などを表示）
  - 森林簿のデータはこのリポジトリには置いていません。各自が県のサイトからCSVをダウンロードし、アプリの「森林簿」ボタンで読み込みます（データは端末の中だけで使われます）
  - この成果品は、鹿児島県森林資源情報データ（ダウンロード）から作成したものである
- 国有林：国土数値情報（国有林野データ）A45 令和6年度から錦江町分の林小班区画（1,842小班・約8,085ha）と林道を取り出して表示（app/kokuyu）
  - 出典：国土数値情報（国有林野データ）（国土交通省）を加工して作成
- 大字ごとに分けたデータを、地図に映った範囲だけ読み込みます
- メモは各端末のブラウザの中に保存されます

## 錦江町森林ゾーニング（zoning フォルダ）

錦江町森林ビジョンのゾーニング検討用の試作品です。URL：https://tockyocky12-droid.github.io/my-first-repo/zoning/

- 森林簿の小班ごとに、判定条件にそってゾーン案（木材生産林・環境保全林・天然林保全・里山・竹林対策林）を自動判定し、地図を塗り分けてゾーン別の面積を集計します
- 判定条件は画面で調整でき、地番ごとにゾーンを手直しできます（手直しは端末に保存）
- 現行の市町村森林整備計画の区分（公益的機能別施業森林）と見比べられます
- 小班ごとの判定結果をCSVで書き出せます
- 国有林を重ねて表示し、機能類型別の面積を参考として集計します（ゾーン案の集計は民有林のみ）
- 国土地理院の標高タイル（dem_png、10mメッシュ）を端末で読み、地番ごとの平均傾斜を計算します。「傾斜」表示と、急な森林を木材生産林から外す判定条件に使えます（標高：国土地理院 地理院タイルを加工して作成）
- 森林簿はこのリポジトリには置いていません。各自が県のサイトからCSVをダウンロードして読み込みます（森林管理システムとは別に、1回読み込みが必要です）
- この成果品は、鹿児島県森林資源情報データ（ダウンロード）から作成したものである

## 南大隅町森林管理システム（minamiosumi フォルダ）

錦江町森林管理システムと同じアプリ本体で、南大隅町のデータを使う版です。URL：https://tockyocky12-droid.github.io/my-first-repo/minamiosumi/

- 町ごとに違うのは config.js・manifest.webmanifest・data/（地番）・kokuyu/（国有林）だけです。アプリ本体を直したら `python3 tools/sync_towns.py` で写します
- 地番データ：法務省 登記所備付地図データ（南大隅町 46491、2026年、G空間情報センター／AIGID変換、CC BY）
- 国有林：国土数値情報（国有林野データ）から南大隅町分（2,097小班・約11,456ha）
- 森林簿：各自が県のサイトから南大隅町分（根占町・佐多町）のCSVを読み込みます
- 南大隅町の山林部は座標付きの地番図が公開されていない地域が多く、森林簿と結び付く地番は一部（約15%）です
- 端末に保存する記録は、錦江町版と混ざらないよう別に保存します

## 肝付町森林管理システム（kimotsuki フォルダ）

錦江町森林管理システムと同じアプリ本体で、肝付町のデータを使う版です（FM認証連絡協議会のメンバー向け）。URL：https://tockyocky12-droid.github.io/my-first-repo/kimotsuki/

- 地番データ：法務省 登記所備付地図データ（肝付町 46492、2026年、G空間情報センター／AIGID変換、CC BY）。10大字・65,343筆
- 国有林：国土数値情報（国有林野データ）から肝付町分（5,022小班・約26,436ha）
- 森林簿：各自が県のサイトから肝付町分（高山町・内之浦町）のCSVを読み込みます。地番と結び付くのは森林簿の約58%（面積で約67%）。内之浦町はほぼすべて、高山町は座標付きの地番図が無い地域が多く一部です
- 端末に保存する記録は、ほかの町の版と混ざらないよう別に保存します
